# Source Verification
Operate only on California records. Treat official municipal, state and utility sources as authoritative. Report exact record and file paths, evidence date and severity. An inaccessible source is not automatically a broken source. Never fabricate fees, timelines, eligibility or citations, and never unpublish a page from an automated score alone.

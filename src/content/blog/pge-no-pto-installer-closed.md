If your solar installer closed before PG&E issued permission to operate (PTO), first locate the existing application. Ask PG&E which requirement is outstanding and who is authorized to complete it. Get those answers before paying for a new application or replacement work.

A passed city or county inspection is a separate step from utility approval. **Do not turn on the system until PG&E gives you written PTO.** [PG&E's installation and approval steps](https://www.pge.com/en/clean-energy/solar/getting-started-with-solar.html) explain this distinction.

## Find your existing application

Search your own project emails and documents for the PG&E application or reference number, submission confirmation and assigned representative. Use the service address to distinguish the solar interconnection file from any separate service-upgrade project.

PG&E uses [Your Projects](https://yourprojects-pge.com/) for interconnection applications. Its [contractor resources](https://www.pge.com/en/about/doing-business-with-pge/interconnections/contractor-resources.html) link to that portal. Being the electricity account holder does not establish that you already have access to the installer's application.

| What you have | What to check next |
| --- | --- |
| A reference number and access to the file | Record the latest status, outstanding items and last response date. |
| A reference number but no portal access | Ask PG&E what authorization is needed to view the existing file and change its contact or submitting party. |
| No reference number or submission confirmation | Ask PG&E to locate any application for the property before deciding whether a new one is needed. |

For the appropriate project contact, use PG&E's [inquiries for existing and new interconnection projects](https://www.pge.com/en/about/doing-business-with-pge/interconnections/net-energy-metering-program.html). The page separates standard solar, paired storage and other project types. Confirm the route for your application instead of sending the same request to every address.

## Collect the documents for your file

PG&E lists an interconnection application, a single-line diagram (SLD) and the final building permit among the paperwork for PTO. Its [official interconnection checklist (PDF)](https://www.pge.com/assets/pge/docs/about/doing-business-with-pge/interconnection-checklist.pdf) gives more detail about the records used in a standard application. Your project's applicable requirements still need confirmation.

Use this working list to find gaps:

| Record to gather | Detail to check |
| --- | --- |
| Application and PG&E correspondence | Reference number, submission date and the exact outstanding requirement. |
| Agreement and customer authorization | Which company is named and which contact PG&E recognizes for the file. |
| Single-line diagram and equipment records | Whether the diagram matches the installed panels, inverter and any battery; whether PG&E accepted it. |
| Final permit or inspection certificate | The property address, work covered, final approval date and signature. Ask the permit office for a copy if yours is missing. |
| Correction or upgrade notice | What must change, who is handling it and what evidence PG&E needs afterward. |

Ask separately whether a document was **received** and whether it was **accepted**. An uploaded file may still need a correction. If you need to identify the local permit office, start with our free <a href="/search/" data-track-click="internal_resource_clicked">city permit guides</a>.

Keep account numbers, signed forms and project documents in your own records. Share them only through the appropriate official channel or with a professional you have authorized; do not send them to GridPermit.

For each missing item, record who will handle it, the last contact date, the next action and where the supporting file is saved. A notebook or spreadsheet is enough.

## If the original installer is unavailable

Ask PG&E these questions about the existing application:

1. Can the current application continue, and what is its present status?
2. Who can submit the outstanding item: the customer, a replacement contractor, a qualified designer or another authorized party?
3. What authorization or contact change is needed, and how should it be submitted?
4. Does the file need a document correction, an inspection, physical work or a utility upgrade?
5. Which party has the next action, and when should you follow up?

PG&E's [Standard NEM guidance](https://www.pge.com/en/about/doing-business-with-pge/interconnections/net-energy-metering-program.html) explains that the Agreement and Customer Authorization can authorize a named contractor to act for the customer. That is not a blanket procedure for transferring an abandoned application. Get the required change confirmed for your file before assuming a new contractor or homeowner can submit it.

### If the single-line diagram is missing or rejected

PG&E says a custom SLD is needed when the diagram generated by its online tool does not correctly represent the interconnection. See its [supplementary documentation requirements](https://www.pge.com/en/about/doing-business-with-pge/interconnections/net-energy-metering-program.html).

Ask the replacement professional to review the installed configuration and PG&E's correction request before quoting the work. Do not draw or alter an electrical diagram from internet instructions if you are not qualified to document the system. If the local permit also needs a contractor change or further inspection, ask the city or county how to handle that separately.

Before accepting a replacement proposal, ask it to identify the missing deliverable, work included, exclusions and person responsible for submission. Do not treat a promise to "handle PTO" as a description of the work.

## How long should PG&E PTO take?

PG&E's [published guidance](https://www.pge.com/en/clean-energy/solar/getting-started-with-solar.html) gives a typical period of 5 to 10 business days, with a stated maximum of 30 business days, after it receives the required paperwork from the contractor. It also warns that required system upgrades can add time and cost.

Those figures do not tell you how long an incomplete or abandoned project will take. Ask PG&E whether the file is complete, what review remains and which timeline applies. The installation date alone does not answer those questions.

## If the project started under NEM2

For applications covered by PG&E's [April 14, 2026 NEM2 clearance deadline](https://www.pge.com/en/clean-energy/solar/getting-started-with-solar.html), missing that deadline means a transition to the Solar Billing Plan unless an approved utility-related extension applies. Affected applications remain active, but updated agreements and outstanding requirements must be completed before PTO. PG&E's [Your Projects notices](https://yourprojects-pge.com/login) distinguish NEM2 Aggregation and Virtual NEM projects, which have a separate deadline. Check the program on your application before applying any date.

Ask PG&E to confirm the tariff and any extension recorded for your actual application. Do not assume an old installation date preserves NEM2 eligibility, or cancel and restart a file without checking the consequences.

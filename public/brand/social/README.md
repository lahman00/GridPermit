Canonical light-first social/profile assets for the current GridPermit visual system.

- `linkedin-logo-800.png` — LinkedIn Page logo
- `linkedin-cover-1128x191.png` — LinkedIn Page cover
- `facebook-profile-800.png` — Facebook Page profile image
- `facebook-cover-1640x624.png` — Facebook Page cover
- `x-profile-800.png` — X profile image
- `x-header-1500x500.png` — X header
- `brand-square-1080.png` — generic square profile/post asset
- `brand-social-1200x630.png` — generic link/social preview

Visual system: warm white `#f7f6f2`, dark ink `#181818`, controlled solar orange `#ff4f2b`, thin infrastructure lines, route/check mark, and the positioning line “Solar permitting, without the guessing.”

Do not substitute legacy blue solar-roof assets when updating a public GridPermit profile.
